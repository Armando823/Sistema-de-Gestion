1) Copia estos archivos sobre tu proyecto (respetando las carpetas).
2) Elimina los archivos que sobran y limpia el repo (una sola vez):

   git rm .github/dependabot1.yml LIMPIAR-REPO.txt
   git rm -r --cached node_modules frontend/node_modules frontend/dist
   git add .
   git commit -m "Privacidad de ordenes, CI, dependabot y limpieza del repo"
   git push

(--cached no borra nada de tu disco; solo deja de subirlo a GitHub.)
